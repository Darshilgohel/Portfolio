# Darshil Gohel, portfolio

A static, single-page portfolio. No build step and no dependencies.

## Structure

- `index.html`: the whole site (HTML, CSS, and a small script)
- `assets/`: profile photo and project images

## Run locally

Open `index.html` in a browser.

## Deploy

1. Push this folder to a GitHub repository, with `index.html` at the repo root.
2. In Vercel, choose Add New Project and import the repository.
3. Leave the framework preset as "Other" and the build command empty, then deploy.

Every push to the main branch redeploys the site.
